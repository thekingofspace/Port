Lehua

A runtime for Luau written in Rust on top of mlua and tokio. You write Luau, run it straight away, then build the whole project into one standalone program that needs no Rust and no source files. It ships a standard library covering the filesystem, networking, SQLite, Mongo, regex, cryptography, serde, processes, parallel virtual machines and a cross VM messenger, with written docs for every module.

A global topic hub, so parallel Luau states can publish to each other

struct Event {
    sub_id: u64,
    args: Vec<PortableValue>,
}

struct HubEntry {
    id: u64,
    topic: String,
    tx: Sender<Event>,
}

fn hub() -> &'static Mutex<Vec<HubEntry>> {
    static HUB: OnceLock<Mutex<Vec<HubEntry>>> = OnceLock::new();
    HUB.get_or_init(|| Mutex::new(Vec::new()))
}

impl Local {
    fn unsubscribe(&self, id: u64) -> bool {
        let removed = self.handlers.borrow_mut().remove(&id).is_some();
        if removed {
            hub().lock().unwrap().retain(|e| e.id != id);
        }
        removed
    }
}

Pigeon

Most Roblox games create one RemoteEvent per feature and then hand write the startup fix, the access checks and the cleanup for every single one. Pigeon takes that job away. You name a channel on the server, name the same channel on the client, and the two are talking. Hundreds of channels share a pool of at most 32 remote slots, early messages are held and delivered in order, and channels can be guarded, grouped into rooms, wrapped in middleware or backed by a table that replicates on write.

Buffer

Expanded buffer tooling that forwards every unknown index to the built in buffer library, so it drops straight in as a replacement. On top of that it adds a chainable writer and reader, variable length integers, packed formats, and readers and writers for Vector2, Vector3, CFrame, Color3 and UDim2. Anything that changes a length returns a fresh buffer, because buffers in Luau are fixed size.

Variable length integers, bounds checked against the real buffer length

function Buffer.WriteVarUInt(b: buffer, offset: number, value: number): number
	checkBuffer(b, "b", "WriteVarUInt")
	local rest = math.floor(value)

	if rest < 0 then
		fail("WriteVarUInt", ("value must be non-negative, got %s (use WriteVarInt)"):format(tostring(value)))
	end

	local at = math.floor(offset)
	local len = buffer.len(b)

	while rest >= 0x80 do
		if at >= len then
			fail("WriteVarUInt", ("ran past the end of a %d byte buffer"):format(len))
		end
		buffer.writeu8(b, at, bit32.bor(bit32.band(rest, 0x7F), 0x80))
		rest //= 128
		at += 1
	end

	if at >= len then
		fail("WriteVarUInt", ("ran past the end of a %d byte buffer"):format(len))
	end

	buffer.writeu8(b, at, rest)
	return at + 1
end

LehuaClass

A class system for Luau with real visibility. Public and private members, statics, metamethods, single and picked inheritance, traits with only, except and rename filters, composed traits, delegation, interfaces checked at build time, get and set controls, plus abstract and sealed classes. Written strict and native.

Named actions with chords and modifiers, contexts you can push and pop, holds, repeats, taps, double taps and sequences, one dimensional axes and two dimensional vectors with deadzones, drag tracking, and live rebinding that captures whatever the player presses next.

ReplicationPP

Per player asset replication. The server stages a snapshot of an instance for chosen players without blocking, marks it persistent so late joiners get it too, and can revoke it later. The client reads assets out of a local folder, waits on one by name with a timeout, and fires signals as copies arrive and leave. One module resolves to the server or client half at require time, so both sides share a single type.

Blackbox

Structured logging and fault handling. Named loggers in a tree, levels, structured fields, breadcrumbs, spans and traces, metrics, a ring buffer of recent history, throttling, guards, serialization and pluggable sinks including an in memory sink you can query in tests. Retries and attempts live in the same place as the logs that record them.

Socket Contributor

This one is not mine. Socket is an existing project that I contributed to rather than authored, and it belongs here as collaboration rather than as a credit. Roblox has no real sockets, so it puts an event based layer over RemoteEvents shaped like socket.io, with independent channels, listeners you can add once or remove, targeted emits, remote calls that wait for a reply with a timeout, broadcasts that skip a player, rooms, incoming and outgoing middleware, and a ping that measures real latency. Working on it is a good part of why Pigeon later took the shape it did.
