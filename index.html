Lehua, a Luau runtime written in Rust

You write Luau, run it straight away, then build the whole project into one standalone program that needs no Rust and no source files. Built on mlua and tokio, with a standard library covering the filesystem, networking, SQLite, Mongo, regex, cryptography, serde, processes, parallel virtual machines and a cross VM messenger.
